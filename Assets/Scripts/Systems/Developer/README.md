# Developer/ 模块文档

## 模块概述
- **主要职责**: 仅用于开发调试的管理入口（加物品、调参数、施加Buff、存/读档等）
- **设计原则**: 与正式玩法解耦；不作为运行时业务依赖
- **依赖关系**: 依赖 `Core` 与多个 `Systems`（调试工具允许更宽松依赖）

## 脚本清单与说明
| 脚本文件 | 核心类名 | 职责描述 | 状态 |
|:---|:---|:---|:---|
| `DeveloperManager.cs` | `DeveloperManager` | 调试入口：加物品、调数值、Buff、存/读档 | ✅ |

## 对外接口/依赖
- **依赖的模块**: `Core/*`, `Systems/*`
- **对外提供的接口**: 无（仅开发调试使用）
