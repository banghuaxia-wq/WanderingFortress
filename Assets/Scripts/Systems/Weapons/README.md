# Weapons/ 模块文档

## 模块概述
- **主要职责**: 武器相关的通用运行时对象（例如投射物）与可扩展子模块
- **设计原则**: 与物品系统解耦；投射物逻辑尽量保持可复用
- **依赖关系**: 依赖 `Core/Data`（如有需要）与 Unity 引擎组件

## 脚本清单与说明
| 脚本文件 | 核心类名 | 职责描述 | 状态 |
|:---|:---|:---|:---|
| `Projectile/Projectile.cs` | `Projectile` | 投射物：飞行、碰撞、命中处理 | ✅ |

## 对外接口/依赖
- **依赖的模块**: 无（系统层内部使用）
- **对外提供的接口**: 无
