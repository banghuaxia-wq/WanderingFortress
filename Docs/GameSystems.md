# 游戏系统设计（第一版）

## 一、角色系统
- 玩家控制
  - 移动（WASD）、冲刺（消耗体力）、俯视角射击（鼠标瞄准，左键射击）
  - 交互（E键）：搜刮、与建筑/商人交互
  - 道具快捷栏（数字键）：快速使用道具（如灵魂球、医疗包）
- 状态系统
  - 基础属性：生命值、体力值、饥饿值、负重值。
  - 环境抗性：低温抗性、高温抗性。与当前环境温度实时计算，若抗性不足，则施加对应的环境 Debuff（如：冻伤-持续掉血、体力消耗加快；中暑-水分加速消耗、视野模糊）。
  - Buff/Debuff 系统：一个独立的状态管理系统，用于管理所有临时效果。
    - 来源包括：环境、哈奇、食物、药物等。
    - 效果可叠加、可刷新时长。
    - 每个效果包含：唯一 ID、图标、描述、持续时间、效果逻辑（如：速度提升 20%）。

## 二、哈奇驯服系统（细化版）
### 驯服前置条件与流程
1. 发现与侦察
   - 玩家靠近一个可驯服的哈奇（无论是打晕后的还是和平驯服类型的）。
   - 此时，哈奇身上会自动浮现一个交互 Tooltip UI。
2. 交互 Tooltip UI 内容
   - 哈奇头像与名称（如：火龙果刺猬）。
   - 所需物品：显示其最喜爱的物品图标（如：奶皮子糖葫芦）。
   - 数量需求：显示为 当前背包拥有数量 / 驯服所需数量（如：1/3）。
   - 状态指示：
     - 可驯服（高亮）：当 背包拥有数量 >= 驯服所需数量。
     - 不可驯服（灰色）：当 背包拥有数量 < 驯服所需数量。
3. 执行驯服
   - 只有当 Tooltip 为高亮可交互状态时，玩家才能按下交互键（E）。
   - 按下后，直接从玩家背包中扣除所需数量的特定物品。
   - 播放一个简短的驯服成功动画（如光芒融入哈奇身体）。
   - 驯服成功后，自动使用一个空灵魂球，将该哈奇收纳入库。

### 数据结构与配置
1. 哈奇数据表（`HatchData_SO`）
   - `hatchID`: 唯一标识符
   - `displayName`: 显示名称（火龙果刺猬）
   - `preferredItemID`: 最喜爱物品的 ID（链接到物品表）
   - `tameCost`: 驯服所需该物品的数量
2. 物品数据表（`ItemData_SO`）
   - `itemID`: 唯一标识符
   - `itemName`: 显示名称（奶皮子糖葫芦）
   - `icon`: 物品图标
   - `itemType`: 物品类型（如：材料、食物、任务物品等）

### 系统工作流程（伪代码）
```csharp
// 当玩家进入哈奇的触发范围内
OnPlayerEnterTrigger(Hatch hatch):
    // 1. 获取此哈奇的驯服信息
    ItemData preferredItem = hatch.Data.preferredItem;
    int cost = hatch.Data.tameCost;
    // 2. 查询玩家背包
    int playerInventoryCount = player.Inventory.GetItemCount(preferredItem.itemID);
    // 3. 更新并显示 Tooltip
    UI_Tooltip.Show(hatch, preferredItem, playerInventoryCount, cost);
    // 4. 设置交互状态
    if (playerInventoryCount >= cost) {
        UI_Tooltip.SetInteractable(true); // 高亮
    } else {
        UI_Tooltip.SetInteractable(false); // 灰色
    }

// 当玩家按下交互键(E)
OnPlayerInteract():
    if (UI_Tooltip.isActiveAndInteractable):
        // 再次验证背包数量
        if (player.Inventory.GetItemCount(preferredItem.itemID) >= cost):
            // 执行驯服
            player.Inventory.RemoveItem(preferredItem.itemID, cost); // 消耗物品
            hatch.PlayTameAnimation();
            player.Inventory.UseEmptySoulOrb(); // 消耗一个空灵魂球
            player.HatchCollection.Add(hatch.Data); // 哈奇入库
            hatch.Despawn(); // 移除场景中的野生哈奇
```

## 三、战斗系统
- 武器系统
  - 武器基础：每个武器有基础伤害、射速、后坐力、弹药类型等属性。
  - 弹药系统：弹药独立于武器，是消耗品。
    - 常规弹药：造成纯伤害。
    - 眩晕弹药：伤害略有衰减，但命中后附加大量眩晕值。
  - 近战武器：
    - 伤害型（如刀剑）：高伤害，无眩晕。
    - 眩晕型（如球棒）：低伤害，高眩晕。
- 伤害计算（V1.0）
  - 最终伤害 = (武器基础伤害 - 目标防御) * 暴击系数
  - 暴击为概率触发，造成 1.5 倍或 2 倍伤害。
  - 注：不同伤害类型与抗性系统留作后续扩展。

## 四、搜集与掉落系统
- 搜刮机制：对准可交互容器（箱子、保险柜、尸体）按 E，播放简短动画后，打开一个随机掉落界面。
- 掉落配置：使用 ScriptableObject 配置每个容器或敌人的掉落列表（Loot Table），包含物品 ID、数量、概率、稀有度。
- 稀有度视觉：物品背景色或边框色代表稀有度（白、绿、蓝、紫、红）。

## 五、建造与科技系统
- 建造机制
  - 网格摆放：进入建造模式后，场景显示虚拟网格。
  - 固定预制体：从建筑菜单选择要建造的物体，一个半透明的预制体幽灵会跟随鼠标。
  - 旋转：按 R 键以 90 度为增量旋转预制体。
  - 放置验证：绿色代表可放置（资源足够、位置合法），红色代表不可放置。
- 自动化指派
  - 与特定功能建筑（如农田）交互，打开其管理界面。
  - 界面中有一个“指派哈奇”的槽位，点击后可以从一个列表（你拥有的、闲置的、且能从事此工作的哈奇）中选择一只进行指派。
  - 被指派的哈奇会自动从灵魂球中释放，并在建筑附近执行任务。

## 六、经济系统
- 商人：
  - 商品列表固定，无限供应。
  - 回购机制：仅在当前交易会话中，玩家出售给商人的物品会出现在一个“回购”分页，玩家可以原价买回。一旦关闭商人界面，回购列表清空。
  - 商人只收购他们商品列表内存在的物品类型。

## 七、地图系统
- 第一张地图：和平的起始区域。生态群系统一，资源温和，敌人威胁低，主要用于教学和体验核心循环。
- 单次进入：玩家从基地选择一张地图进入，完成目标（搜刮、撤离）后返回基地。
- 撤离点：地图上有明确标识的撤离点，到达后互动并读条即可成功撤离。
